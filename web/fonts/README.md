# Fonts for the website

Self-hosted, so the site loads nothing from other sites. Every font here is licensed under the SIL Open
Font License 1.1; each folder holds its `OFL.txt`. The files are **unmodified** copies from Google's font
repository (https://github.com/google/fonts, branch `main`, folder `ofl/`), downloaded on 4 October 2026;
only the file names were changed (brackets removed). IBM Plex carries the Reserved Font Name "Plex", so it
must not be subset or otherwise modified under that name.

| Folder | Family | Used for | Source folder |
|---|---|---|---|
| `big-shoulders-display/` | Big Shoulders Display (variable weight) | display headings | `ofl/bigshouldersdisplay/` |
| `ibm-plex-sans/` | IBM Plex Sans (variable width and weight) | body text | `ofl/ibmplexsans/` |
| `ibm-plex-mono/` | IBM Plex Mono (Regular, Medium, SemiBold) | every number and ID; the meter's readout | `ofl/ibmplexmono/` |
